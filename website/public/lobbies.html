Host a game

  1. Open Host in the game menu and select a save file.
  2. Set a port and start the co-op session.
  3. Give your address and port to the other player.

On the same network, use the host computer's local IP address. For an internet connection, the host needs a reachable address and UDP port forwarding.

Join a game

Open Join, enter the host's address and matching port, choose your character, then connect. Use the same game version on both computers.

A shared server

A central lobby service is possible, with a separate server running the room service and UDP relay. GitHub Pages can host these pages, but cannot run either server process.

The repository includes room-service tools and a UDP relay. Public listings and integration with the new native menu still need work before players can join from this site.

The website does not list private room codes or collect addresses. When a public service is ready, this page will link to its real lobby list.
