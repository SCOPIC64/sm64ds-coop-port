Install & update

  1. Download and extract the Windows ZIP.
  2. Keep your existing game data in the portable folder, including build/assets/romdata.bin. The release does not contain cartridge data.
  3. Open sm64ds coop.exe. Choose Host and a save file for solo play or a co-op game.

When updating, replace the program and release documents. Keep save, your settings, custom music and backgrounds, and any mods or textures you edited.

├─ sm64ds coop.exe

Install a Lua mod

Extract a mod into mods/<mod-name>, with main.lua directly inside that folder. Single .lua files can also go directly in mods. Open Mods, choose Refresh Mods, then enable the mod. New mods start disabled.

The next preview adds multi-file folders: main.lua runs first, followed by the other Lua files in alphabetical order. All files share the mod's globals and sandbox.

SM64 Movement is included as a separate mod. Enable it for N64-style Mario movement; disable it for native DS movement. Your selection is stored in mods/enabled.txt.

Gameplay scripts currently run in solo adventure. Existing CoopDX scripts need adapting to the DS Lua API.

Create a texture pack

  1. Open Mods → Texture Pack Tools → Start Texture Capture.
  2. Play the areas whose textures you want to replace.
  3. Return to Texture Pack Tools and choose Create Pack From Capture.
  4. Edit the PNGs in the new pack's assets folder. Keep their filenames.
  5. Restart the game to load the pack.

Packs live in mods/resource-packs. Creating a pack always makes a new folder. Prefix a pack folder with off_ to disable it.

Unedited captures contain artwork from your game. Keep those local; share your own replacement images.

SM64 camera & pause controls

Select Options → Camera → SM64 Cam.

KeyAction
Q / ETurn the camera by 45°
FZoom out
RZoom in, then C-Up inspection while standing
WASDLook around in C-Up mode
VSwitch Lakitu / Mario camera
CReset behind Mario
Enter / Escape / controller StartOpen or close the adventure pause menu

Native text and save prompts keep their confirmation controls. The upcoming preview fixes Enter opening Pause over a textbox.

Submit a mod or texture pack

The repository owner approves modders. Approval allows reviewed submissions; it does not automatically publish your work.

  1. Ask the maintainer to add your GitHub username to the approved-modder list.
  2. Publish your source and download on GitHub. Include the DS API version and installation folder.
  3. Add your entry to website/public/catalog.json in a pull request.
  4. A maintainer reviews it and merges the catalogue change before publication.

Visitors cannot upload files to this site. See the catalogue submission guide for the metadata format.
