SUPERMARIO 64 DSCO-OP

Welcome!

SM64DS Co-op is a community PC port of Super Mario 64 DS, with co-op adventure, Lua mods, texture packs and a new menu.

Pick a save file, host a game, or play solo. The Windows preview includes the SM64 camera, an optional SM64 Movement mod, and menu backgrounds and music you can change.

Frequently asked questions

How do I install or update the game?

Extract the ZIP, add your own game data, and run sm64ds coop.exe. Keep your saves, settings and edited mods when updating. See the installation guide.

Can I use CoopDX mods?

DS mods use the DS Lua API. CoopDX scripts need adapting because the games have different player and level systems. Gameplay Lua currently runs in solo adventure.

Can I host a public lobby?

The current menu supports direct connections. Public browsing and a hosted lobby service are still being integrated. See lobbies for the current options.

How do I submit a mod?

The repository owner approves modders. Approved creators submit catalogue entries through GitHub, and every submission is reviewed before publication. Submission guide.
