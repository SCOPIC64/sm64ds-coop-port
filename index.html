Super Mario 64 DS Multiplayer Co-op Port
An engine port bringing full online and local multiplayer co-op functionality to Super Mario 64 DS. Experience classic levels together with custom mod support.
Browse Mods Hub Community Forums
Project Overview

SM64DS Coop Port is an open-source project created by SCOPIC64 designed to allow seamless co-op multiplayer.

Multiplayer Synchronization

Full player movement, object, and level state synchronization over network connection.

Lua & Custom Modding

Integrates a modding engine allowing community developers to load custom scripts, assets, and game logic.

Character Capabilities

Supports DS character mechanics and expanded movesets across all stages.

Custom Repositories

Integrated mod distribution system through the official Mods Hub.
Getting Started
  1. Obtain the project source code from the official GitHub repository.
  2. Follow build instructions detailed in the repository documentation.
  3. Download custom mods from the Mods Repository Hub.
