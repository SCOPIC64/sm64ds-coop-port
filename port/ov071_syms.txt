# The ov071 data SCUTTLEBUG names -- the spider-legged Scuttlebug, daSpd_c
# (actor 255), and the state machine its two dispatchers drive.
#
# ov071 is an ACTOR overlay (base 0x0211f000) carrying four classes -- Scuttlebug
# (255), MrI/BigMrI (198/199, the eyeball), MrI_Projectile (262?) and Coffin
# (218) -- of which THIS gate hosts only Scuttlebug. Its id and its SpawnInfo's
# own +4 halfword were read from the arm9 ACTOR_SPAWN_TABLE (0x02090864): entry
# 255 (0x02090864 + 255*4 = 0x02090c60) relocates to Scuttlebug_SpawnInfo at
# 0x02122c08, and that record's +4 halfword reads 0x00ff = 255. Its +0 word
# relocates to Scuttlebug_Spawn (0x02120618).
#
# This is the per-symbol mount (the gate-83/gate-50 ov095/ov080 shape):
# SCUTTLEBUG reaches its SpawnInfo, the two SharedFilePtr statics its
# InitResources loads and CleanupResources releases (data_ov071_02122f80 model,
# data_ov071_02122f88 anim, plus their aux blocks f90/f9c the sinit wires), the
# eighteen state-record SOURCE PMFs the sinit copies, and the bss state array
# that copy lands in, all BY NAME. --pack keeps the bss run (f80..fa8) at the
# ROM's own spacing so the SharedFilePtr handles and the state array stay one
# contiguous object.
#
# THE VTABLE IS LEFT OUT, the ov095/ov080 rule: _ZTV10Scuttlebug (= _ZTV7daSpd_c,
# 0x02122c2c) carries the vtable signature (its +4 word relocates to
# Actor::BeforeInitResources, arm9 0x02011268) and is a HOST array the registry
# fills (hal/actor_classes_scuttlebug.cpp).
#
# THE STATE TABLE. Scuttlebug_SetState stores &data_ov071_02122fa8[idx] (16-byte
# stride, ADD r1,r2,r1,LSL#4) into this+0x380; two dispatchers read that stored
# pointer as an mwcc {fn, delta} PMF -- func_ov071_021202b4 reads record+0 (the
# state's ENTER half), func_ov071_02120278 reads record+8 (the state's MAIN
# half, called by Behavior every frame). The bss array data_ov071_02122fa8 (0x90
# = 9 records of 16 bytes, an {enter, main} pair each) is FILLED by
# __sinit_ov071_021226ac, which copies the eighteen 8-byte SOURCE PMFs at
# data_ov071_02122b60..02122be8 into it. Those SOURCE words hold DS CODE
# ADDRESSES, so the seat (Scuttlebug_StateDispatch.cpp) rewrites each SOURCE PMF
# with its host body BEFORE the sinit copies it -- the MontyMole/Crate treatment,
# ROM-checked. The source PMFs and the bss destination are both in this mount.
#
# data_ov071_02122f80 / _02122f88 are the model and anim SharedFilePtr handles;
# _02122f90 / _02122f9c are the aux blocks the sinit passes to their
# constructors (0x020731dc). All bss; --pack keeps the delta-sized run contiguous.
#
# Scuttlebug_SpawnInfo is pinned to the record's real 0x1c so the +4 id halfword
# the registry cross-checks reads out of the right bytes (255); the next-symbol
# delta (0x24, into the vtable) would over-size it into a host/ROM gap.
