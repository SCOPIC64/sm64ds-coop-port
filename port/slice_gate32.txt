# Gate 32: Bob-omb Battlefield's living cast.
#
# Six classes -- GOOMBA, BOB_OMB, BOB_OMB_BUDDY, CHAIN_CHOMP, KING_BOB_OMB and
# KOOPA_THE_QUICK -- and they are the first ENEMY-family actors the port hosts.
# Everything before this gate was furniture, ambience or a Platform.
#
# ---- what an Enemy costs that an Actor does not ---------------------------
#
# THIRTY-ONE VTABLE SLOTS, not twenty. Actor appends thirteen virtuals of its
# own after ActorBase's eighteen -- OnYoshiTryEat, OnTurnIntoEgg, Virtual50 and
# the nine combat hooks (OnGroundPounded, OnAttacked1/2, OnKicked, OnPushed,
# OnHitByCannonBlastedChar, OnHitByMegaChar, OnHitFromUnderneath) plus the two
# egg ones -- and every one of these classes is reached through them. Read out
# of the ROM's own tables: _ZTV6Goomba (ov084 0x02130948) and _ZTV6BobOmb
# (ov102 0x0214e558) both run 0x7c bytes, and slot 20 in each is
# Actor::Virtual50. The classes the port carried before declared their vtable
# arrays [20] because nothing on the castle grounds dispatched past 19; an
# enemy that Mario can jump on does, so hal/actor_classes_bob_enemy.cpp
# declares [31] and fills all of them.
#
# THE CALLERS COUNT ROM SLOTS. Every ov002 combat path that dispatches one of
# these -- func_ov002_020b36b4 and its family -- builds a LOCAL SHADOW CLASS
# with thirty-one virtuals and dispatches through that, so the numbering the
# host array is filled in is the numbering the call site uses. It is the
# header-compiled direction that would diverge (MSVC folds D1/D0 into one
# slot, so its OnYoshiTryEat is 17 where the ROM's is 18) and no TU in the
# port's build takes it.
#
# ---- what needed a host copy ----------------------------------------------
#
# FIVE OF THE SIX RENDERS. Each dispatches slot 5 of its own ModelAnim through
# a local shadow class, which is the ModelAnim slot-5 collision gates 17, 21
# and 23 already wrote down: _ZTV9ModelAnim cannot be dual-filled the way
# _ZTV5Model can, because MSVC's slot 5 there is Virtual18 and it takes a
# second argument. Bodies in port/unmatched/BobEnemy_Renders.cpp.
# KingBobOmb::Render is the exception -- it calls Model::Render by its Itanium
# C name rather than through a shadow -- so it comes from src/ unchanged.
