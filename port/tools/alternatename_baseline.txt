# alternatename_baseline.txt
#
# The frozen allowlist of /alternatename directives whose LHS is DELIBERATELY
# defined in the full walk_window link -- the port's weak-symbol idiom, in
# three reviewed shapes:
#
#   * fallback stubs that only fire in reduced binaries: tests/fault_probe.h's
#     no-walker/no-level/no-players/no-frame family, the cxxname_bridge
#     shadow fallbacks, heap_vtable's align4 fallback, the l7 particle stub,
#     the actor_faces_bob faces. In walk_window the real definition links and
#     the stub dies to /OPT:REF -- by design.
#   * MSVC-mangle faces/forwarders coexisting with the Itanium body (the w4-c
#     LoadFile forwarder shape; MemoryLeft, FindWithID, Enable): references
#     bind to the face, the face forwards to the body.
#   * data bridges whose LHS became hosted after the alias landed
#     (data_0209f2d8, data_ov021_021149c0, EnemyC2).
#
# port/tools/alternatename_guard.py fails the build if the linked map shows a
# defeated alias NOT on this list -- that is the R1/R2 arrival shape (a newly
# sliced TU defining an alias LHS at its own address; w5b_review.md). This
# list is a RATCHET: it can only SHRINK. When an alias here is deleted or its
# routing moves to a per-source -D rename, regenerate with:
#     python port/tools/alternatename_guard.py --update
# Never add a pair here by hand to unblock a build.
#
# One LHS=RHS pair per line, sorted.
