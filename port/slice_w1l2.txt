# WHAT A LINE HERE BUYS, AND WHAT IT DOES NOT. Adding a TU compiles it and
# hands it to the linker, but the link runs with /OPT:REF (Release, no
# /DEBUG), so an object nothing references is dropped again before the map is
# written and the TU does not count as linked. Measured on this branch:
# src/func_02058158.c added on its own built its .obj, linked clean, and left
# linkage.py at 3881. Every line below therefore arrives with a reference
# edge in one of this lane's hal files -- a vtable slot the ROM's own table
# names, or the face a linked caller already calls.
